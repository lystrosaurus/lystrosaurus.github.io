## 通用

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+P` | 快速打开文件 |
| `Ctrl+Shift+N` | 新窗口 |
| `Ctrl+,` | 设置 |
| `Ctrl+K Ctrl+S` | 键盘快捷键 |

## 编辑

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+D` | 选中下一个相同词 |
| `Ctrl+Shift+L` | 选中所有相同词 |
| `Alt+↑/↓` | 上/下移动行 |
| `Shift+Alt+↑/↓` | 上/下复制行 |
| `Ctrl+/` | 切换行注释 |
| `Ctrl+Shift+/` | 切换块注释 |
| `Ctrl+Shift+K` | 删除行 |
| `Ctrl+Enter` | 下方插入行 |
| `Ctrl+Shift+Enter` | 上方插入行 |

## 导航

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+G` | 跳转到行 |
| `F12` | 跳转到定义 |
| `Alt+F12` | 查看定义（预览） |
| `Shift+F12` | 查找所有引用 |
| `Ctrl+T` | 工作区符号搜索 |
| `Ctrl+Shift+O` | 文件内符号 |

## 多光标

| 快捷键 | 功能 |
|--------|------|
| `Alt+Click` | 添加光标 |
| `Ctrl+Alt+↑/↓` | 上/下添加光标 |
| `Ctrl+U` | 撤销上一个光标 |

## 终端

| 快捷键 | 功能 |
|--------|------|
| `` Ctrl+` `` | 切换终端 |
| `Ctrl+Shift+` `` | 新建终端 |
| `Ctrl+C` | 复制（选中时）/ 中断 |

## 搜索

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+F` | 文件内搜索 |
| `Ctrl+H` | 文件内替换 |
| `Ctrl+Shift+F` | 工作区搜索 |
| `Ctrl+Shift+H` | 工作区替换 |

## 分屏

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+\` | 水平分屏 |
| `Ctrl+1/2/3` | 切换编辑器组 |
| `Ctrl+W` | 关闭当前标签 |
